4.2 Integration Fundamentals

Integration is one of the two fundamental operations of calculus. Whereas differentiation determines the rate at which a quantity changes, integration determines the accumulated effect of a quantity over an interval. One important application of integration is the calculation of areas beneath curves.

4.2.1 Area Under a Curve

Consider the function \(y=f(x)\). The shaded region below represents the area between the curve and the \(x\)-axis over a specified interval, \([a,b]\).

The area between the curve, the \(x\)-axis and the vertical lines \(x=a\) and \(x=b\) can be determined using integration.

Definition
Integration can be used to calculate the area under a curve between two specified values of the independent variable.

4.2.2 Integration as the Reverse of Differentiation

Recall that differentiation allows us to determine the derivative of a function. For example,

\[ \frac{\mathrm{d}}{\mathrm{d}x}(x^2)=2x \]

Working backwards, if

\[ \frac{\mathrm{d}y}{\mathrm{d}x}=2x, \]

then

\[ y=x^2 \]

This process of working backwards is called integration. The relationship between differentiation and integration is illustrated below.

4.2.3 Integration Notation

The symbol used to represent integration is

\[ \int \]

which is known as the integral sign.

Definition

An expression of the form

\[ \int f(x)\, \mathrm{d}x \]

means:

“Find a function whose derivative is \(f(x)\).”

The symbol

\[ \mathrm{d}x \]

indicates that integration is being performed with respect to \(x\).

For example,

\[ \int 2x\, \mathrm{d}x \]

asks us to find a function whose derivative is \(2x\). Since

\[ \frac{\mathrm{d}}{\mathrm{d}x}(x^2)=2x, \]

it follows that

\[ \int 2x\, \mathrm{d}x=x^2 \]

However, this answer is incomplete.

4.2.4 The Constant of Integration

The derivative of a constant is always zero. For example,

\[ \frac{\mathrm{d}}{\mathrm{d}x}(x^2+3)=2x \]

and

\[ \frac{\mathrm{d}}{\mathrm{d}x}(x^2-8)=2x \]

Therefore many different functions possess the same derivative.

Definition

Every indefinite integral must include a constant

\[ +C \]

called the constant of integration.

Therefore

\[ \int 2x\, \mathrm{d}x=x^2+C \]

4.2.8 Applications of Integration

Engineering Application
A definite integral can be used to determine the area between a curve and the horizontal axis over a specified interval. This is one of the most important applications of integration and forms the basis of many engineering calculations.
Engineering Application
If velocity is given as a function of time, \(\mathrm{v}(t)\), then integration can be used to calculate displacement. In other words, integration reverses the differentiation process that converts displacement into velocity.
