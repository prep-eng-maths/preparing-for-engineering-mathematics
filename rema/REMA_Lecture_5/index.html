Intro

Argand Diagram

Argand Diagrams

Complex numbers written in the form

\begin{equation*} z=x+jy \end{equation*}

are said to be in Cartesian form (also called rectangular form).

In this form we can represent a complex number graphically using the co-ordinate \((x,y)\) in an Argand diagram, where the \(x\)-axis is the real part and the \(y\)-axis represents the imaginary part.

Modulus and Argument

The Argand diagram suggests an alternative way of representing complex numbers.

Instead of using the co-ordinates \((x,y)\) to fix the position of the end of a line in the Argand diagram, we could define the line’s position using the modulus \(r\) (length of the line from the origin) and the argument \(\theta \) (angle relative to the positive real axis).

Conv. to Polar Form

Polar Form

Given a complex number, \(z=\textcolor{red}{x}+ j\textcolor{red}{y}\), where both \(x,y\gt 0\):

We can calculate the modulus using Pythagoras:

\begin{equation*} r=\sqrt{x^2+y^2} \end{equation*}

and the argument can be calculated using trigonometry:

\begin{equation*} \theta =\tan ^{-1} \left(\dfrac {y}{x} \right) \end{equation*}

Polar Form

The shorthand form for \( z=r (\cos \theta + j \sin \theta )\) is

\begin{equation*} z= r \angle \theta \ \ \ \ \text{when dealing with complex numbers.} \end{equation*}

Or

\begin{equation*} P= (r, \theta ) \ \ \ \ \text{when specifying a point in polar co-ordinates.} \end{equation*}

Measuring the Argument

If \(z\) is not in the first or fourth quadrant, we need to do more to find the argument, as it is measured anti-clockwise from the positive real axis. By convention, it should be in the range \(-\pi \lt \theta \leq +\pi \):

Measuring the Argument - an example:

Consider:

\begin{equation*} z = -6 -j3 \end{equation*}

This complex number is in the third quadrant.

But this is not the argument, rather:

\begin{equation*} \theta = \alpha -\pi = -2.678 \end{equation*}

Measuring the Argument

The general approach is to always calculate \(\theta \) according to:

\begin{equation*} \theta =\tan ^{-1} \left(\dfrac {y}{x} \right) \end{equation*}

and then:

  • If the complex number lies in quadrant II on the Argand diagram, then we add 180\(^o\) or \(\pi \) to the result.

  • If the complex number lies in quadrant III on the Argand diagram, then subtract 180\(^o\) or \(\pi \) from the result.

Conv.to Cartesian Form

Converting to Cartesian Form

Given a complex number written in polar form:

\begin{equation*} z= r( \cos \theta + j \sin \theta ) \end{equation*}

We are easily able to convert to Cartesian (rectangular) form, using trigonometry, with the formulae:

\begin{equation*} x= r \cos \theta \hspace{5mm} \text{and} \hspace{5mm} y=r \sin \theta \end{equation*}

Note that in this case in does not matter which quadrant the complex number lies in.

Exponential Form

Exponential Form

It can be shown using Maclaurin series’ (not a topic we’ll encounter) that

Exponential Form:

\begin{equation*} r \operatorname {e}^{j \theta } = r\cos (\theta ) + jr\sin (\theta ) \end{equation*}

where \(r\) is the modulus and \(\theta \) is the argument.

But the RHS of this is a polar form complex number, hence if

\begin{equation*} z=\textcolor{red}{x}+j\textcolor{red}{y} \ \ \text{and} \ \ |z|= \textcolor{blue}{r} \ \ \text{while} \ \ \text{arg}(z) = \textcolor{blue}{\theta }, \end{equation*}

then \(z=\textcolor{blue}{r}\cos (\textcolor{blue}{\theta }) + j \textcolor{blue}{r}\sin (\textcolor{blue}{\theta })\) (polar form) and \(z=\textcolor{blue}{r}\operatorname {e}^{j \textcolor{blue}{\theta }}\) (exponential form).

Example 3

Rewrite \(z=5 \angle \dfrac {\pi }{6}\) in exponential form.

Example 3 - Solution

In expanded polar form, this can be written as

\begin{equation*} z=5\cos \left(\dfrac {\pi }{6}\right) + j5\sin \left(\dfrac {\pi }{6}\right). \end{equation*}

Here \(r=5\) and \(\theta =\dfrac {\pi }{6}\).

Therefore, this can be expressed in exponential form as

\begin{equation*} z= 5 \operatorname {e}^{j\frac{\pi }{6}} \end{equation*}
