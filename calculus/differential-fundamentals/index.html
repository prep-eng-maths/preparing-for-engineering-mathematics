4.1 Differential Fundamentals

Differentiation is one of the most important concepts in mathematics. It allows us to determine how quickly one quantity changes with respect to another. In engineering, differentiation is used to calculate quantities such as velocity, acceleration, force, power, and flow rates.

Definition

The derivative of a function measures its rate of change. If

\[ y=f(x) \]

then the derivative of \(y\) with respect to \(x\) represents how rapidly \(y\) changes as \(x\) changes.

4.1.1 Gradients and Rates of Change

Recall that the gradient of a straight line is given by

\[ \frac{\text{change in }y}{\text{change in }x} \]

For a curve, the gradient is not constant and generally changes from point to point.

Calculating the gradient of a curve is not straightforward, as the gradient varies along the curve, i.e. it depends on \(x\), as we can see in the images above.

Definition
The gradient of a curve at a particular point is equal to the gradient of the tangent to the curve at that point.

A tangent line is a straight line that only just touches the curve at exactly that particular point. So we could draw such a line at the point we were interested in, as shown in the figure below:

Then we would set up a triangle (as in linear cases) to calculate the gradient of the tangent. But this method is not practical.

Differentiation provides a mathematical method for determining this gradient.

4.1.2 Notation

Several equivalent notations are used for derivatives.

Definition

If \(y=f(x)\), then the derivative may be written as

\[ \frac{\mathrm{d}y}{\mathrm{d}x} \]

\[ y' \]

or

\[ f'(x) \]

These all represent the same quantity.

Engineering Application

If \(s\) denotes displacement and \(t\) denotes time, then

\[ \frac{\mathrm{d}s}{\mathrm{d}t} \]

represents the rate of change of displacement with respect to time. This quantity is called the velocity.

Engineering Application

If \(v\) denotes velocity and \(t\) denotes time, then

\[ \frac{\mathrm{d}v}{\mathrm{d}t} \]

represents the rate of change of velocity with respect to time. This quantity is called the acceleration.
