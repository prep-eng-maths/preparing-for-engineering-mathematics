3.5 Exponential Functions

Exponential functions are used to model situations in which a quantity grows or decreases by a constant percentage over time. They arise naturally in engineering, finance, population growth, radioactive decay, and many other real-world applications.

Definition

An exponential function is a function in which the independent variable appears as a power. A general exponential function can be written as

\[ y=Ab^{kx} \]

where \(A\) is a constant coefficient, \(b\) is the base, \(k\) controls the rate of growth or decay and \(x\) is the independent variable.

In engineering and science, the most important exponential function uses the mathematical constant

\[ \operatorname {e} \approx 2.71828 \]
Definition

A common form of the exponential function is

\[ y=A\operatorname {e}^{Bx}+C \]

where \(A\), \(B\) and \(C\) are constants. When \(x=0\),

\[ y=A\operatorname {e}^0+C=A+C, \]

so the \(y\)-intercept is equal to \(A+C\).

3.5.1 The Graph of an Exponential Function

The simplest exponential function is

\[ y=\operatorname {e}^x \]

Its graph has the following shape.

Definition

The exponential function

\[ y=\operatorname {e}^x \]

has the following properties:

  • The graph passes through \((0,1)\).

  • The domain is all real numbers.

  • The range is \(y\gt 0\).

  • The graph never crosses the \(x\)-axis.

  • The \(x\)-axis is a horizontal asymptote.

  • The function increases as \(x\) increases.

3.5.2 Transformations of Exponential Functions

The constants in

\[ y=A\operatorname {e}^{Bx}+C \]

affect the shape and position of the graph.

Definition

For the function

\[ y=A\operatorname {e}^{Bx}+C, \]

  • Increasing \(|A|\) stretches the graph vertically.

  • The value of \(A+C\) determines the \(y\)-intercept.

  • Increasing \(|B|\) makes the graph steeper.

  • If \(B\gt 0\), the function exhibits exponential growth.

  • If \(B\lt 0\), the function exhibits exponential decay.

  • The constant \(C\) shifts the graph vertically.

3.5.5 Applications of Exponential Functions

Engineering Application

Populations are often modelled using exponential functions.

\[ P=P_0\operatorname {e}^{kt}, \]

where \(P_0\) is the initial population and \(k\) is the growth rate. If \(k\gt 0\), the population increases exponentially over time.

Engineering Application

Radioactive materials decay according to an exponential law.

\[ N=N_0\operatorname {e}^{-kt}, \]

where \(N_0\) is the initial quantity and \(k\) is a positive constant. The negative exponent causes the quantity to decrease over time.

Engineering Application

Exponential functions frequently arise in engineering applications, including:

  • capacitor discharge,

  • Newton’s law of cooling,

  • vibration damping,

  • atmospheric pressure models,

  • belt tension calculations.
