3.6 Trigonometric Functions

Trigonometry is the branch of mathematics concerned with the relationships between angles and lengths in triangles. Trigonometric functions are widely used throughout engineering, physics, surveying, navigation, and signal analysis.

3.6.1 The Trigonometric Functions

Trigonometric functions take an angle as their input. Throughout this section we shall work in degrees. There are three primary trigonometric functions:

The Sine Function

The sine function varies smoothly between \(-1\) and \(1\).

The graph repeats every \(360^\circ \).

The Cosine Function

The cosine function also varies between \(-1\) and \(1\).

The graph repeats every \(360^\circ \).

The Tangent Function

Unlike sine and cosine, the tangent function does not remain between fixed limits.

The function is undefined at \(90^\circ \) and \(270^\circ \). The graph repeats every \(180^\circ \).

3.6.4 Non-Right-Angled Triangles

For non-right-angled triangles, the trigonometric ratios above are insufficient. Instead, we use either:

  • the sine rule,

  • the cosine rule.

The Sine Rule

Definition

The sine rule states that

\[ \frac{a}{\sin (A)} = \frac{b}{\sin (B)} = \frac{c}{\sin (C)} \]

3.6.5 Applications of Trigonometry

Engineering Application

Trigonometry is used to determine distances and heights that cannot easily be measured directly. Common applications include:

  • measuring the height of buildings,

  • determining the distance to offshore structures,

  • navigation and positioning systems.

Engineering Application

Engineers use trigonometry when analysing structures, forces, mechanisms and components that contain angled members. Examples include:

  • truss structures,

  • cranes,

  • bridges,

  • mechanical linkages.
