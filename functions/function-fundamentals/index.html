Functions are one of the most important ideas in mathematics. They allow us to describe how one quantity depends upon another. Functions appear throughout engineering, science and technology. For example, the distance travelled by a train depends upon its speed and the time for which it travels. Similarly, the voltage across an electrical component may depend upon the current flowing through it. Many of the equations studied in the previous chapters are examples of functions. In this chapter we shall formalise the idea of a function and learn how to work with function notation, tables and graphs.

3.1 What is a Function?

Definition
A function describes how one variable depends on one or more other variables. For every permitted input value there must be exactly one output value.

For example,

\[ y = 2x + 3 \]

is a function because every value of \(x\) produces exactly one value of \(y\). When \(x=1\),

\[ y=2(1)+3=5 \]

and when \(x=4\),

\[ y=2(4)+3=11 \]

The same rule is simply applied to different values of \(x\). A useful way to think about a function is as a machine:

\[ \text{Input} \rightarrow \text{Rule} \rightarrow \text{Output} \]

The input enters the function, the function rule is applied and the output is produced.

3.1.1 Independent and Dependent Variables

Functions describe relationships between variables.

Definition
The independent variable is the variable whose value is chosen. The dependent variable is the variable whose value depends upon the independent variable.

Consider

\[ y = 2x + 3 \]

The value of \(x\) can be chosen freely. The value of \(y\) depends entirely upon the chosen value of \(x\). Therefore:

  • \(x\) is the independent variable.

  • \(y\) is the dependent variable.

Engineering Application

Suppose a train travels at a constant speed of \(20\, \mathrm{m/s}\). The distance travelled is given by

\[ d=20t \]

where \(d\) is the distance travelled and \(t\) is the time. As the time increases, the distance increases. Here \(t\) is the independent variable and \(d\) is the dependent variable.

3.1.2 Function Notation

Functions are often written using function notation. Instead of writing

\[ y=x^2+2x \]

we may write

\[ f(x)=x^2+2x \]

The notation \(f(x)\) means the value of the function when the input is \(x\). A common mistake is to think that \(f(x)\) means \(f\times x\). It does not. The symbols \(f\), \(g\) and \(h\) are simply names given to functions.

\[ f(x),\qquad g(x),\qquad h(x) \]

are all valid function names.

3.1.5 Function Graphs

A graph provides a visual representation of a function. Each point on the graph corresponds to an input-output pair. For example, the table

\[ (0,1),\ (1,3),\ (2,5),\ (3,7) \]

can be plotted on a graph and joined to form a straight line.

Different functions produce different graph shapes. For example:

  • Constant functions produce horizontal lines.

  • Linear functions produce straight lines.

  • Quadratic functions produce curved parabolas.

These functions will be studied in detail later in the chapter.

3.1.6 Domain and Range

Not every function accepts every possible input value. Similarly, not every output value may be possible.

Definition

The domain of a function is the set of allowable input values.

The range of a function is the set of possible output values.

Example: Linear Function

Consider

\[ f(x)=2x+1 \]

Any real number can be substituted for \(x\). Therefore the domain consists of all real numbers and the range consists of all real numbers.

Example: Quadratic Function

Consider

\[ f(x)=x^2 \]

Any real number may be substituted. However, squaring a number can never produce a negative value. Therefore:

  • Domain: all real numbers.

  • Range: \(y\ge 0\).

Example: Square Root Function

Consider

\[ f(x)=\sqrt{x} \]

Negative values cannot be placed under the square root sign. Therefore:

  • Domain: \(x\ge 0\).

  • Range: \(y\ge 0\).

Consider the following table.

\(x\)

\(y\)

2

5

2

8

The input \(2\) produces two different outputs. Therefore, this does not represent a function.

The same idea can be applied to graphs.

Definition
A graph represents a function if every value of \(x\) corresponds to only one value of \(y\).

For example:

  • A straight line is a function.

  • A parabola is a function.

  • A circle is not a function, as some values of \(x\) correspond to two values of \(y\).

3.1.8 Common Mistakes

Common errors when working with functions include:

  • Thinking that \(f(x)\) means \(f\times x\).

  • Forgetting brackets when substituting negative values.

  • Confusing the independent and dependent variables.

  • Assuming every equation represents a function.

  • Forgetting that each input must have only one output.

  • Confusing domain and range.
